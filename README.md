## 🧩 How I Build

```text
Problem
   │
   ▼
Understand the workflow
   │
   ▼
Build the smallest useful version
   │
   ▼
Test with real usage
   │
   ▼
Find the bottleneck
   │
   ▼
Automate / simplify
   │
   ▼
Ship
   │
   └──────────────► Repeat
```

> **I don't want to build complicated software.**
>
> I want to build software that makes complicated work feel simple.
